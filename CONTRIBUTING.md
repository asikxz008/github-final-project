# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md).

## Report a problem or suggest an improvement

Open an issue describing the problem or idea. For bugs, include the input
values, actual result, and expected result.

## Submit a change

1. Fork this repository and create a branch for your change.
2. Make a focused change and check it with `bash simple-interest.sh`.
3. Commit with a meaningful message.
4. Open a pull request explaining the change and how you checked it.
